Field Hospital Calculator Suite

Quick Start — Load Calculator (Pro)

Version 1.1.3

1. What this calculator does

This calculator estimates electrical load for a field hospital–style site in more detail than the Basic version. It uses both kilowatts (useful power) and kilovolt-amperes (a common way generators are rated), lets you adjust how each item is modeled electrically where the form allows, estimates extra demand when large equipment first starts, suggests a generator size that considers both steady running load and that starting spike, and can estimate fuel runtime. You can adjust built-in equipment values and add custom rows. It is for planning and engineering review support, not as a substitute for a qualified electrical engineer’s final design.

2. Before you start

  • Rough equipment list and quantities, including any items not on the standard lists (you can add custom rows).
  • If known, the actual generator size you want to check against (in kVA).
  • Optional: fuel tank capacity and consumption assumptions for runtime.
  • A scenario name and notes if you plan to save versions.

3. How to use it — step by step

  1. Open the Load Pro calculator from the suite.
  2. Go through each category and enter quantities. Where the table allows, adjust power draw per item and the power factor (PF) for each row if your equipment differs from the defaults.
  3. Use Add custom row where needed, and remove rows you do not need.
  4. Use search to focus the list; the sidebar shows totals for all equipment and, when searching, subtotals for visible rows.
  5. Review the summary: running load, peak starting demand, recommended generator size, and the generator capacity check against the size you enter (including status such as adequate margin, tight, insufficient, or peak-start failure).
  6. Optional: enter fuel information for approximate runtime.
  7. Use category resets or full sheet reset tools if you need to start over.
  8. Save, export, or print when the plan is ready.

4. Understanding the results

Running load describes steady operation. Peak starting reflects a conservative estimate of the worst moment when a large motor-type load starts while other equipment is already running — important for picking a generator that will not trip or overload. Recommended generator size takes the larger of that peak need and a standard continuous-load margin. The capacity check shows how your plan compares to a real generator you specify. Fuel runtime is a simple estimate from load and tank data. Together, these support sizing discussions and engineering review; they are not a code-compliant study by themselves.

5. Saving your work

Save a named scenario with Save scenario when you want a version you can reload later in this browser. Use Export to file to keep a backup or send your plan to someone else. If something disappears from the screen, try Restore Autosave on the toolbar to recover the last automatically saved worksheet state.
