Field Hospital Calculator Suite

Quick Start — Full Calculator Suite

Version 1.1.3

1. What is this tool?

This is the Field Hospital Calculator Suite, a browser-based planning tool for field hospital deployment. It helps clinical and logistics teams estimate consumable supplies, pharmaceutical needs, water requirements, and electrical (generator) load. You do not need to install software; it runs in your web browser when you open it from the folder you were given.

2. How to open the tool

  1. Locate the file you received — either a zip file or a folder.
  2. If it is a zip file, right-click it and choose Extract All (Windows) or double-click to unzip (Mac).
  3. In the top-level folder (the one that contains 0_START_HERE_Click_to_Open_Calculator.html and the FieldCalcs folder), double-click 0_START_HERE_Click_to_Open_Calculator.html. It sends you straight into the suite. If nothing happens, use the link on that page, or open FieldCalcs/index.html directly.
  4. You do not need to open the individual calculator folders — use the tabs at the top of the suite to switch between calculators.
  5. The tool will open in your web browser.
  6. If asked which browser to use, choose Chrome or Edge.
  7. Use the buttons at the top of the page to switch between calculators.

3. The five calculators

Consumables

Ward/ICU consumable quantities from built-in lists, scaled by deployment length, beds, and optional buffer.

Pharmaceuticals

Medication quantities from built-in ward or ICU lists using your deployment details.

Water

Potable and wastewater volumes and delivery or pickup timing over the deployment.

Load Basic

Total electrical load (kilowatts) from standard lists versus an available generator—simpler than Load Pro.

Load Pro

Detailed load including equipment startup demand, generator sizing, and optional fuel runtime.

4. Saving your work

The tool saves your in-progress work automatically in the background as you use it. You can also save named scenarios to come back to later in the same browser. Use Export to create a file you can keep as a backup or share with others. For the most reliable experience, use the suite in one browser tab at a time — avoid opening the same tool in several tabs at once.

5. If something goes wrong

If the page looks blank or broken, try a hard refresh: press Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac). If some of your work seems missing, use the Restore Autosave button on the toolbar of the calculator you were using; that brings back the last automatically saved state without changing your saved named scenarios.
