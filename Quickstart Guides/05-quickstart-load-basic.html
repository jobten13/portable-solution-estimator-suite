Field Hospital Calculator Suite

Quick Start — Load Calculator (Basic)

Version 1.1.2

1. What this calculator does

This calculator estimates generator electrical load for a field hospital–style site using kilowatts (kW) only. You enter how many of each listed equipment items you expect to run, and it totals load, suggests a rough generator size using an 80% loading rule, and lets you check your plan against an available generator. It also supports optional fuel tank and runtime estimates. It is simpler than the Pro version (no separate “power factor” or peak motor-starting math). Use it for planning conversations; final electrical design needs a qualified engineer.

2. Before you start

  • A list or rough count of major equipment you expect (the calculator groups items by category).
  • Optional: the available generator size in kW you want to compare against.
  • Optional: fuel tank size and planning values for fuel use, if you want a runtime estimate.
  • A scenario name and any notes or assumptions you want stored with a saved plan.

3. How to use it — step by step

  1. Open the Load Basic calculator from the suite.
  2. Expand equipment categories and enter quantities for each item you expect to use. The tool multiplies quantity by each item’s fixed kW to build row and category totals.
  3. Use search if you need to find equipment quickly; the sidebar can show both total load for everything and, while searching, load for only what is visible.
  4. Review the load summary in the sidebar: total connected load, recommended generator size at 80% loading, and — if you entered it — how your load compares to available generator capacity (including a simple status such as adequate margin, tight, or insufficient).
  5. Optional: enter fuel information to see approximate runtime.
  6. Use Reset Quantities to zero amounts only, or Reset Worksheet for a fuller clear including scenario fields and search.
  7. When satisfied, save a scenario, export, or print as needed.

4. Understanding the results

Total connected load is the sum of all equipment you entered — your main planning total. Filtered view load appears when you search and shows load for visible rows only, to support focused review. Recommended generator applies a standard continuous-load margin (planning at 80% of generator capacity). The capacity check compares your total to a generator you specify so you can see percent used and a quick status. Fuel runtime is an estimate from your tank size and consumption assumptions. All of this supports preliminary generator and fuel planning, not final engineering sign-off.

5. Saving your work

Save a named scenario with Save scenario when you want a version you can reload later in this browser. Use Export to file to keep a backup or send your plan to someone else. If something disappears from the screen, try Restore Autosave on the toolbar to recover the last automatically saved worksheet state.
