Scenarios

  • Save Scenario stores your current quantities, generator and fuel inputs, and notes in this browser.
  • Use a clear scenario name and brief notes so assumptions are easy to understand later.
  • Load restores a scenario, Delete removes one, and Clear all removes all saved scenarios.
  • Export lets you choose JSON (backup/re-import) or CSV (human-readable report); Import restores from an exported JSON scenario file.
  • Toolbar “Worksheet autosaved” is recovery data for the open worksheet. Restore last autosave reloads it after a refresh; use Restore before editing if you need the previous session.
