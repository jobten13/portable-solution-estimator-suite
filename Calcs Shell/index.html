Running kW is continuous power. PF (power factor) matters for motor/non-linear loads (default 1.0 for resistive/IT). Peak kVA drives generator capacity.

Load calculation summary

  • kVA vs kW: Running kVA = kW ÷ power factor (PF). Resistive/IT loads use PF 1.0; motors use lower PF.
  • Peak starting kVA: Motors can draw 4× running kVA at start. Generator must meet this peak.
  • Totals shown: Main totals are all items. When search is active, filtered-view subtotals are shown for analysis.
  • Recommended size uses safety factor ÷0.8. Final generator must meet both peak kVA and recommended kVA.
