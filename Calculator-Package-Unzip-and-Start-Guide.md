# Calculator Package - Unzip and Start Guide

Use this quick guide when sending the calculator package by email.

## 1) Download and save the ZIP file

1. Download the attached ZIP file from email.
2. Save it to a location you can find easily (for example, Desktop or Documents).

## 2) Unzip the package

1. Right-click the ZIP file.
2. Select **Extract All...** (Windows) or your system's unzip option.
3. Choose a destination folder.
4. Open the extracted folder when complete.

## 3) Start a calculator

1. Open the extracted package folder.
2. Open the calculator you want (for example: Load Calc Basic, Load Calc Pro, Consumables Calc, Medicines Calc).
3. Double-click the calculator's `index.html` file.
4. The calculator should open in your default browser.

## 4) If double-click does not open correctly

1. Right-click `index.html`.
2. Choose **Open with**.
3. Select a modern browser (Edge, Chrome, or Firefox).

## 5) Save, export, and share

- Scenario saves are local to that browser on that device.
- Use each calculator's **Export** function to create a file for backup/sharing.

## 6) Important note

These tools are planning estimators. Final technical decisions should be verified by qualified personnel.
